# Support

Use GitHub Issues for reproducible bugs, installation problems, documentation
requests, and feature proposals.

Include:

- plugin version or commit;
- operating system and Node.js version;
- the command or workflow step that failed;
- sanitized logs and a minimal configuration;
- expected and actual behavior.

Never include tokens, page IDs, private repository content, or private Notion
content. Report security issues through GitHub private vulnerability reporting
as described in `SECURITY.md`.
